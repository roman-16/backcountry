# Backcountry

A Minecraft modpack about a year alone in the Alaskan wilderness, for Minecraft 1.21.1 on NeoForge, solo or as a team. You arrive at a lake on 3 May with a small kit, and calories, cold, fire, hunting and fishing decide whether you last. Its rules ship in the Backcountry mod.

## Setup

You need [git](https://git-scm.com), [devbox](https://www.jetify.com/devbox) and [direnv](https://direnv.net). Everything else comes from `devbox.json`.

```console
$ git clone https://github.com/roman-16/backcountry.git
$ cd backcountry
$ direnv allow
```

## Play

In Prism Launcher: **Add Instance → Import**, and give it the address of the major version's instance:

```text
https://roman-16.github.io/backcountry/1/Backcountry.zip
```

Before every launch the instance fetches what changed in the newest 1.x version.

To release a version, give it its dated section in `CHANGELOG.md` (`## [1.2.3] - 2026-11-19`) and push it to main: the Release workflow lints it, builds it and makes it the GitHub release of its version, which GitHub Pages serves. `just pack` builds the same into `dist/` locally.

To play the pack in a dev client, on a fresh world:

```console
$ just play
```

The dev client runs without the shader and the far view, at 8 chunks; `just play shipped` keeps both as the pack ships them.

To see what a seed's world looks like before playing it:

```console
$ just shape 1 2 3   # build/shape/1.png, 2.png, 3.png
```

Running a server means you accept the [Minecraft EULA](https://aka.ms/MinecraftEULA): `just server` and `just test` write `eula=true` for you.

## Tasks

| Task | Does |
|---|---|
| `just boot` | Builds the server pack and boots it headless |
| `just build` | Builds the Backcountry mod |
| `just clean` | Removes everything generated by builds and runs |
| `just compile` | Compiles the Backcountry mod and its dev code |
| `just devserver` | Runs the dev server in the foreground |
| `just exaroton <server>` | Builds the server pack and puts it on the exaroton server, uploading only what changed; needs `EXAROTON_API_TOKEN` in `.env`, laid out as in `.env.example` |
| `just gametest` | Runs the mod's game tests headless |
| `just generate` | Draws the textures, sprites and models from `generator/` |
| `just lint` | Generates, formats and lints everything |
| `just pack` | Exports the Prism instance, the hosted pack, the jar and the server pack into `dist/` |
| `just play` | Opens the pack in a dev client on a fresh world |
| `just registries` | Writes everything the running pack holds into `build/reports/` |
| `just server` | Runs the pack's dedicated server locally |
| `just shape <seeds>` | Draws each seed's world into `build/shape/` |
| `just sources` | Unpacks Minecraft's code and decompiles every mod into `build/sources/` for searching |
| `just test` | Runs the game tests beside the headless boot |
| `just update` | Moves every mod and tool to its newest version, then lints and tests |
